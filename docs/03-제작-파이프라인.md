# 제작 파이프라인 (v0.1)

```
이미지 AI (설정화 → 파츠 PNG) ─┐
TTS (대사 음성 mp3/wav) ────────┼─> Remotion 코드 (Claude 작성) ─> MP4 ─> 유튜브
대본 (docs/episodes) ───────────┘
```

## 1. 이미지 → 파츠 PNG 규격
캐릭터 하나당 아래 파츠를 **투명 배경 PNG**로 준비합니다.
파일은 `public/assets/characters/<캐릭터>/` 에 넣습니다.

| 파일명 | 설명 |
|---|---|
| `body.png` | 몸통 (팔·꼬리 제외) |
| `head.png` | 머리 (눈·입 없는 빈 얼굴) |
| `ear-l.png`, `ear-r.png` | 귀 |
| `arm-l.png`, `arm-r.png` | 팔 (어깨 끝이 위쪽에 오게) |
| `tail-1.png` ~ `tail-3.png` | 꼬리 마디 (뿌리 → 끝) |
| `eye-open.png`, `eye-closed.png` | 눈 (한쪽만 만들어 양쪽에 같은 그림 사용. **좌우 반전 금지**: 하이라이트 방향이 바뀌기 때문) |
| (코드) 눈 하이라이트 | 큰 원 = 눈동자 왼쪽 위, 작은 원 = 오른쪽 아래. 양쪽 눈 동일 |
| `brow.png` | 눈썹 |
| `mouth-*.png` | 입: neutral / smile / open-s / open-m / open-l / sad / angry / o |

규칙
- 모든 파츠는 **같은 크기·같은 시점(정면)** 에서 그린 그림에서 잘라낼 것
- 파츠끼리 겹치는 부분(어깨, 목)은 조금 넉넉하게 남길 것 → 움직일 때 틈이 안 생김
- 표정은 눈·눈썹·입 조합으로 만들고, 얼굴 전체를 새로 그리지 않음

## 2. Remotion 구조
| 경로 | 역할 |
|---|---|
| `src/characters/` | 캐릭터 리그 (파츠 배치 + pivot + 감정·말하기·손흔들기) |
| `src/scenes/` | 장면 |
| `src/lib/anim.ts` | 공용 움직임 (숨쉬기, 깜빡임, 통통 등장) |
| `public/assets/` | 이미지 에셋 |
| `public/audio/` | TTS 음성 |

현재 `src/characters/Doto.tsx`는 도형으로 그린 **임시 캐릭터**입니다. 파츠 PNG가 들어오면 도형만 이미지로 바꾸고 움직임 코드는 그대로 씁니다.

## 3. TTS 후보
| 서비스 | 장점 | 확인할 점 |
|---|---|---|
| ElevenLabs | API가 좋아서 Claude와 연동이 가장 쉬움, 감정 표현 좋음 | 한국어가 국내 서비스보다 어색할 수 있음. 상업적 이용은 유료 플랜만 |
| 타입캐스트 (Typecast) | 한국어 아이·캐릭터 목소리가 많음, API 있음 | 상업적 이용 가능한 플랜 확인 |
| Google Cloud TTS / Azure TTS | 저렴하고 무료 사용량이 있음, API 연동 쉬움 | 캐릭터 목소리보다는 내레이션 느낌 |

선정 기준: ① 유튜브 수익화 가능한 라이선스 ② API 제공 ③ 한국어 아이 목소리 품질

## 4. 이미지 AI
파이어플라이(Firefly)는 일반 구독으로는 API를 쓸 수 없는 것으로 보여서(기업 계약 필요), **이미지 생성은 직접 하고 결과 파일을 저장소에 올리는 방식**으로 진행합니다. 파이어플라이는 상업적 이용에 안전한 학습 데이터를 쓴다는 장점이 있습니다.

## 5. 명령어
```bash
npm install          # 처음 한 번
npm run studio       # 브라우저에서 미리보기·편집
npx remotion render TestScene out/test.mp4   # 영상 렌더링
```

## 6. 라이선스 메모
- Remotion: 개인 또는 직원 3명 이하 회사는 무료. 그 이상 규모가 되면 회사 라이선스 필요

## 7. 도토 리그 (완성 1차)
- 코드: `src/characters/DotoRig.tsx` / 확인 장면: `src/scenes/RigTest.tsx`
- 파츠: `public/assets/characters/doto/body/` (머리·귀·애교머리·몸통·팔·다리·꼬리·초커), `face/` (눈·눈썹·입·코)
- 마음 도토리 펜던트는 코드(SVG)로 그림 → 감정별 색 자동 변경
- 기능: 숨쉬기, 눈 깜빡임, 꼬리 살랑, 귀 쫑긋, 감정 6종(표정·눈썹·귀·팔·몸 반응), 말하기 입모양, 손 흔들기
- 위치 조정은 `DOTO_LAYOUT` 한 곳에서

### 파츠 자르기 스크립트
- `scripts/slice_blobs.py`: 초록 배경 시트 → 덩어리별 PNG (AI가 넣은 글자 자동 제거). `pip install scipy` 필요
- `scripts/slice_parts.py`: 칸이 고른 시트용 (격자로 자름)
- `scripts/fix_face_parts.py`: 눈 단색화, 입에서 코 분리 + 기준점 계산
