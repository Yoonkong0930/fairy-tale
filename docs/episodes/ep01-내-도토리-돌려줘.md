# 1화 「내 도토리 돌려줘!」 (대본 초안 v0.1)

| 항목 | 내용 |
|---|---|
| 주제 감정 | 화남 |
| 배울 것 | 화가 나는 건 괜찮아요. 화가 나면 **① 멈추고 ② 후~ 숨 세 번 ③ "나 화났어" 말로 하기** |
| 길이 | 약 3분 30초 |
| 등장 | 도토(아기다람쥐), 콩이(아기토끼, 가칭·새로 디자인 필요), 내레이터(목소리만) |
| 장소 | ① 도토리나무 집 앞 ② 꽃밭 놀이터 |
| 마음 도토리 | 민트 → 노랑 → **빨강** → (숨쉬기) → 민트 → 노랑 → 민트 |

## 매 화 반복되는 틀 (시리즈 공통)
- **오프닝**: 내레이터 "몽글숲에 아침이 왔어요!" → 도토 등장 "도토도토, 궁금해!"
- **가운데**: 사건 → 마음 도토리 색 변화 → 내레이터가 시청자에게 질문 (2초 기다림)
- **마무리 놀이**: 오늘 배운 방법을 시청자와 함께 따라 하기
- **엔딩**: "오늘 도토 마음은 무슨 색이었나요?" → 색깔 복습 → "내일 또 만나요!"

## 장면 1. 오프닝 — 도토리나무 집 앞 (0:00~0:25)
| 화면 | 대사 | 감정 / 목걸이 |
|---|---|---|
| 해가 뜨는 몽글숲. 도토리나무 집 문이 열림 | **내레이터**: 몽글숲에 아침이 왔어요! | |
| 도토가 통통 뛰어나와 기지개 | **도토**: 도토도토, 궁금해! 오늘은 무슨 일이 생길까? | 기쁨 / 노랑 |
| 도토가 반짝이는 동그란 도토리를 꺼내 보여줌 | **도토**: 짜잔! 이건 내 보물 도토리야. 제일 동그랗고 제일 반짝반짝해! | 기쁨 / 노랑 |
| 도토가 보물 도토리를 들고 걸어감 | **내레이터**: 도토는 보물 도토리를 들고 꽃밭 놀이터로 갔어요. | 평소 / 민트 |

## 장면 2. 놀이터 — 보물을 내려놓다 (0:25~0:55)
| 화면 | 대사 | 감정 / 목걸이 |
|---|---|---|
| 꽃밭 놀이터. 나비가 날아감 | **도토**: 와, 나비다! 나비야, 같이 놀자! | 놀람 → 기쁨 |
| 도토가 보물 도토리를 꽃 옆에 살짝 내려놓고 나비를 따라감 | **도토**: 도토리야, 여기서 잠깐 기다려! | 기쁨 / 노랑 |
| 도토가 화면 밖으로 뛰어감. 도토리만 남음 | **내레이터**: 도토는 나비를 따라 저~기까지 갔어요. | |

| 도토가 발을 쿵! 구르고 손을 뻗으려다 멈칫 | **도토**: 내 거야! 내 거라고! | 화남 / 빨강 |
| 화면이 살짝 멈춤(정지 효과). 콩이는 깜짝 놀라 귀가 쫑긋 | **내레이터**: 친구들, 화가 날 때는 어떻게 하면 좋을까요? | 화남 / 빨강 |
