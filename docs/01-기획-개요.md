# 기획 개요 (v0.2)

## 확정된 방향
| 항목 | 결정 |
|---|---|
| 타깃 연령 | 2~4세 |
| 형식 | 이야기 중심 (노래는 추후) |
| 교훈 주제 | 감정 → 생활습관 / 친구관계로 확장 |
| 세계관 | 몽글숲 마을 |
| 주인공 | 호기심 많고 용감한 아기다람쥐 (가칭 '도토') |
| 제작 방식 | 이미지 AI로 배경·캐릭터 파츠 생성 → 리깅 → 코드(Claude)로 애니메이션 |
| 최종 목표 | 영상 IP → 어린이 앱 |

## 2~4세 시청자 특성 → 제작 원칙
- **한 화 3~4분**, 장면 전환은 느리게, 한 화에 사건 하나
- **반복**: 같은 오프닝 · 같은 말버릇 · 같은 마무리 인사
- **감정은 얼굴로 크게**: 표정이 과장되고 분명해야 함
- **색은 선명하고 단순하게**, 캐릭터마다 대표색 1개
- **캐릭터는 둥글고 머리가 큰 비율(2~2.5등신)**, 큰 눈
- 무서운 장면·악당 없음. 갈등은 "내 마음"과 "친구와의 오해" 정도

## 코드 애니메이션을 고려한 캐릭터 설계 원칙
- 팔다리가 짧고 단순할수록 리깅·움직임이 쉬움 (펭귄, 병아리, 곰돌이 유리)
- 털이 길거나 꼬리가 복잡한 동물은 피함
- 파츠 분리 기준: 몸통 / 머리 / 눈(뜬눈·감은눈) / 눈썹 / 입(5~6개 모양) / 팔 / 다리 / 귀 / 꼬리
- 정면 + 3/4 측면 두 방향만 먼저 제작

## 제작 파이프라인 (안)
1. 이미지 AI로 캐릭터 설정화(모델 시트) 확정 — 일관성 확보가 최우선
2. 파츠별 투명 PNG로 분리
3. 배경 레이어 분리 (원경 / 중경 / 근경)
4. Claude가 코드로 애니메이션 작성 — **Remotion 확정** (React 코드 → MP4)
5. 내레이션·대사 음성 입히기 — TTS 사용 (서비스 선정 중)
6. 같은 에셋·코드를 앱에서 재사용
