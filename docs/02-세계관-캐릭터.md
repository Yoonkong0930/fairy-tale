# 세계관 · 캐릭터 (v0.1)

## 세계관: 몽글숲 마을
몽글몽글 둥근 나무와 구름이 있는 숲속 마을. 아기 동물 친구들이 함께 놀고, 함께 자라는 곳.
- 무서운 악당 없음. 사건은 "내 마음"이나 "친구와의 작은 다툼"에서 시작
- 사계절이 뚜렷해서 계절 에피소드를 만들기 좋음
- 주요 장소(안): 큰 도토리나무(주인공 집), 퐁퐁 시냇가, 꽃밭 놀이터, 친구들 집

## 주인공: 아기다람쥐 (가칭 '도토')
| 항목 | 내용 |
|---|---|
| 성격 | 호기심이 많고 용감함. "내가 가볼게!"가 먼저 나옴 |
| 약점 | 너무 앞서가서 친구 마음을 놓치거나, 실수하면 크게 속상해함 |
| 말버릇(안) | "도토도토, 궁금해!" |
| 대표색 | 황갈색 + 민트(마음 도토리) |
| 종 | 한국 다람쥐 (연한 황갈색, 머리·등 갈색 줄무늬) |
| 외형 포인트 | 머리 위 **둥글둥글한 애교머리** (털 뭉치 2~3개) |
| 시그니처 소품 | **마음 도토리 목걸이** (목에 딱 맞는 초커형): 감정에 따라 색이 바뀜 (평소 민트 / 기쁨 노랑 / 화남 빨강 / 슬픔 파랑 / 무서움 보라 / 놀람 주황) |
| 비율 | 2.5등신, 큰 머리, 큰 눈, 짧은 팔다리 |

> 용감한 성격은 "무서움" 에피소드에서 특히 좋아요. 용감한 도토도 무서울 때가 있다는 것, 무서운 마음은 이상한 게 아니라는 걸 보여줄 수 있어요.

### 리깅 메모
다람쥐는 **꼬리가 크다**는 점이 리깅에서 가장 신경 써야 할 부분입니다.
- 꼬리는 2~3마디로 나눠서 각 마디를 순서대로 흔들면 자연스러운 살랑임이 나와요
- 털은 바깥선을 매끈하게(털 뭉치 2~3개 정도만) 디자인할 것

## 친구 캐릭터 (안, 미확정)
| 캐릭터 | 성격 | 주로 다루는 감정 |
|---|---|---|
| 아기토끼 | 겁이 많고 다정함 | 무서움, 걱정 |
| 아기곰 | 고집 세고 힘이 셈, 속은 여림 | 화남, 질투 |
| 병아리 | 수줍고 작음 | 부끄러움, 슬픔 |

## 마음 도토리 (이야기 장치)
- 도토의 감정이 바뀌면 목걸이 색이 바뀐다 → 아이들이 감정을 색으로 알아봄
- 에피소드 구조: 평소(민트) → 사건으로 색 변화 → 마음 다독이기 → 다시 민트
- 앱 확장: "오늘 내 마음은 무슨 색?" 감정 체크
